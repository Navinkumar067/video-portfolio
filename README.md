🎬 Editkaro.in – Creative Video Agency Portfolio

A modern, responsive, and interactive portfolio webpage built for Editkaro.in, a creative social media marketing and video editing agency.
This project showcases multiple categories of video editing work with filtering, animations, and lightbox previews — designed to highlight storytelling and creativity.

🌟 Project Overview

Editkaro.in helps brands and creators amplify their visual presence through engaging video content — from short-form reels to cinematic storytelling.
This web portfolio demonstrates the agency’s style, mission, and body of work in a sleek, responsive layout.

🧩 Key Features
Feature	Description
🎨 Responsive Design	Works perfectly on desktop, tablet, and mobile devices.
🎬 Interactive Portfolio Grid	Displays videos by category (Shorts, Anime, Ads, Documentary, Gaming).
💡 Filter Buttons	Instantly filter the displayed projects by type.
🪄 Lightbox Video Preview	Click any video thumbnail to view it in a fullscreen pop-up.
⚙️ Smooth Animations	Sections fade in with professional transitions.
📱 Mobile Navigation	Hamburger menu toggles smoothly for smaller screens.
💌 Contact Form	Collects visitor messages (mock submission).
🧭 Vision & Mission Section	Animated cards showcasing agency goals and creativity values.
🌐 SEO & Accessibility Optimized	Uses semantic HTML and descriptive alt text for media.
🏗️ Tech Stack

HTML5 — Semantic and accessible structure

CSS3 — Modern responsive design with animations

JavaScript (ES6) — Dynamic filtering, interactivity, and lightbox control

Google Fonts — “Poppins” for clean professional typography
